# TP Java : Gestion des comptes bancaires

## 1. Présentation du TP

Ce travail pratique porte sur la Programmation Orientée Objet (POO) en Java.
  Le sujet consiste à concevoir un programme de gestion des comptes bancaires afin de mettre en pratique les principaux concepts de la programmation orientée objet.
  L'objectif est de comprendre comment structurer un programme en classes, organiser les données et définir les comportements des objets.

## 2. Objectifs pédagogiques

Ce TP vise à maîtriser les notions suivantes :
- **Classes et objets :** comprendre la structure et l'instanciation des objets.
- **Attributs et méthodes :** définir les caractéristiques et les comportements des objets.
- **Constructeurs :** initialiser les objets lors de leur création.
- **Encapsulation :** protéger les données à l'aide des attributs privés et des méthodes d'accès.
- **Héritage :** créer des classes dérivées à partir d'une classe mère.
- **Polymorphisme :** permettre à des objets de différentes classes de répondre différemment à une même méthode.
- **Collections (ArrayList) :** gérer plusieurs comptes bancaires dans une collection.

## 3. Contexte de l'exercice

  Une banque souhaite mettre en place une application permettant de gérer les comptes de ses clients.
  Le programme doit permettre de représenter les comptes bancaires, leurs caractéristiques et leurs opérations à travers une conception orientée objet.
